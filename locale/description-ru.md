# Text Resource Modifier

**Автор**: TheRedDaemon
**Репозиторий**: [ucp_textResourceModifier](https://github.com/UnofficialCrusaderPatch/ucp_textResourceModifier)

Этот модуль позволяет изменять тексты, возвращаемые внутренним текстовым ресурсом. Переведённые тексты игры уже можно заменять, редактируя файл `cr.tex`. Однако такие изменения нельзя вносить динамически во время работы игры, а замена отдельных текстов становится сложнее.

Модуль позволяет заменять конкретные тексты, передавая их в распространённом формате UTF-8. Для этого он перехватывает центральную функцию получения текста в Stronghold Crusader. Из индекса и номера запрошенной строки внутри этого индекса формируется ключ. Если для него зарегистрирован собственный текст, возвращается этот текст; в противном случае используется исходная функция.

API регистрации строк принимает UTF-8 и преобразует текст в текущую кодировку игры.

Сам по себе модуль не добавляет игровых возможностей. Он служит технической основой для других расширений. Дополнительные сведения доступны в README репозитория.

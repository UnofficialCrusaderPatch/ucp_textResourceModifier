# Text Resource Modifier

**Автор**: TheRedDaemon  
**Версия**: 0.3.1  
**Репозиторий**: [ucp_textResourceModifier](https://github.com/UnofficialCrusaderPatch/ucp_textResourceModifier)

Этот модуль позволяет другим модулям менять отдельные тексты игры без изменения
файла `cr.tex`. API принимает текст в UTF-8 и преобразует его в кодировку игры.
Для неизменённых записей используется исходный текст игры.

Изменения разных записей сохраняются одновременно. Для одной и той же записи
действует последняя успешная регистрация. Удаление регистрации восстанавливает
доступ к исходному тексту. Исходный текст UTF-8 сохраняется для повторной
инициализации. Язык и кодировка игры не зависят от языка программы запуска.

Модуль предоставляет технический интерфейс и не содержит непосредственно
включаемых игровых функций. Сведения об использовании и времени жизни текстов
приведены в README репозитория.

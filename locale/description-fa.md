# Text Resource Modifier

**نویسنده**: TheRedDaemon  
**نسخه**: 0.3.1  
**مخزن**: [ucp_textResourceModifier](https://github.com/UnofficialCrusaderPatch/ucp_textResourceModifier)

این ماژول به ماژول‌های دیگر اجازه می‌دهد متن‌های بازی را بدون تغییر فایل
`cr.tex` تغییر دهند. رابط API متن UTF-8 را دریافت می‌کند و آن را به کدگذاری
نویسه‌های بازی تبدیل می‌کند. برای ورودی‌های تغییرنیافته، متن اصلی بازی حفظ می‌شود.

تغییرات ورودی‌های متفاوت هم‌زمان حفظ می‌شوند. برای یک ورودی یکسان، آخرین ثبت
موفق معتبر است. حذف ثبت، دسترسی به متن اصلی بازی را بازمی‌گرداند. متن اصلی
UTF-8 برای تبدیل در مقداردهی اولیهٔ بعدی نگه داشته می‌شود. زبان و کدگذاری
بازی مستقل از زبان برنامهٔ راه‌انداز است.

این ماژول یک رابط فنی ارائه می‌دهد و خودش قابلیت بازی قابل فعال‌سازی مستقیمی
ندارد. برای روش استفاده و مدت اعتبار متن‌ها، فایل README مخزن را ببینید.
